========================================
 B2B 智能開發信群發系統 - 使用說明與本機測試指南
========================================

一、 系統功能簡介
----------------------------------------
1. 開發信內容編輯版面：支援主旨與內文編輯，並支援即時變數替換 ({{companyName}}, {{contactName}})。
2. 動態變數自動對應：信件開頭與內文中的 {{companyName}} 會自動對應至輸入的客戶公司名稱，並提供即時預覽功能。
3. 客戶名單管理：支援手動逐筆新增、載入範例名單、即時預覽與清單刪除。
4. 附件支援：支援同時上傳多個圖片或 PDF 檔案作為信件附件。
5. 雙模式發送：
   - 模擬測試模式：無需設定 SMTP，即時模擬發送並檢視詳細結果報告。
   - 真實 SMTP 模式：支援透過 Gmail 或 Brevo 發送真實郵件。


二、 本機電腦測試步驟 (使用個人 Gmail SMTP)
----------------------------------------
若要在本機電腦上測試真實發送郵件功能（不受雲端主機防火牆限制），請依照以下步驟設定：

1. 準備 Gmail 應用程式密碼：
   - 前往 Google 帳號安全性設定 (https://myaccount.google.com/security)。
   - 開啟「雙重認證 (2-Step Verification)」。
   - 搜尋並建立「應用程式密碼 (App Passwords)」（選擇「郵件」），取得 16 位數密碼。

2. 啟動本機伺服器：
   - 打開命令提示字元 (CMD) 或 PowerShell，進入專案資料夾：
     cd C:\Users\za941\Desktop\群發信
   - 安裝相依套件（若尚未安裝）：
     cmd /c npm install
   - 啟動伺服器：
     cmd /c npm start

3. 操作網頁與 SMTP 設定：
   - 打開瀏覽器前往：http://localhost:3000
   - 切換至「真實 SMTP 模式」。
   - 填入您的 Gmail 相關設定：
     * SMTP 主機 (Host): smtp.gmail.com
     * 連接埠 (Port): 465
     * 寄件者 Email: 您的個人 Gmail 帳號 (例如 your-email@gmail.com)
     * 應用程式密碼: 您的 16 位數 Gmail 應用程式密碼
   - 輸入收件人名單、編輯信件內容與附件後，點擊「立即發送開發信」即可成功發送！
